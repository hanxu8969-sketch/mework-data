## 播客要点（Coinbase's Everything Exchange，Brian Armstrong，2026-09-10）

1. Coinbase 的"Everything Exchange"愿景：股票、大宗商品、加密货币、衍生品、永续合约、预测市场都在同一平台交易，且随监管明朗化正在向更多国家开放。
2. 稳定币支付是继交易业务后 Coinbase 增长最快的板块——即便比特币价格下跌，稳定币支付量仍持续增长，因其"像信息一样快、且便宜"。
3. Agent 电商约 **76% 的交易金额低于30美分**，传统卡组织30美分起的固定手续费完全不适配，这是 Coinbase 推 x402 协议的直接商业动机。
4. **x402** 由 Coinbase 孵化并捐给 Linux Foundation，目前 Google、Cloudflare、AWS 等已加入共建；配套推出 agentic.market 网站，可查看这一新经济的实时支付数据和服务商列表。
5. Armstrong 预判：agent 之间互相调用、互相"打工"（类似 tool call）会催生一批专精细分领域的 agent 服务商，未来"agent 经济体量可能超过人类经济"。

- **该看什么**：x402 协议 + agentic.market 值得加入长期观察清单——这是"AI agent 自主支付"从概念走向具体基础设施（Linux Foundation背书 + 三大云厂商参与）的关键信号，和游戏行业未来的"AI agent 内购/agent-to-agent 交易"场景可能有交叉点。
